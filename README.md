# Sistema de Gestión de Estudiantes

## Descripción
Programa en C que permite gestionar la información de estudiantes.  
Resuelve el problema de registrar, consultar, buscar y eliminar estudiantes de forma sencilla desde la consola.

## Funcionalidades
- Agregar nuevos estudiantes (ID, nombre, carrera y promedio)
- Mostrar la lista completa de estudiantes
- Buscar un estudiante por su ID
- Eliminar un estudiante por su ID

## Tecnologías utilizadas
- Lenguaje: C
- Librería: stdio.h, string.h

## Cómo compilar y ejecutar

### Requisitos
- Compilador de C (gcc, MinGW, o Visual Studio)

### Compilación
```bash
gcc main.c -o gestion_estudiantes
```

### Ejecución
```bash
./gestion_estudiantes
```

En Windows:
```bash
gestion_estudiantes.exe
```
